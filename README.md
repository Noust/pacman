# Pacman

Juego de Pacman tomado de freegames (Grant Jenks) y modificado en equipo.

## Cambios realizados
- Fantasmas más listos: persiguen a Pacman en vez de moverse al azar, sin dar vuelta en U salvo en callejón sin salida (Noust)
- Tablero nuevo y fantasmas más rápidos (Javier)

## Requisitos
- Python 3
- `pip install freegames`

## Controles
Flechas del teclado para mover a Pacman.
